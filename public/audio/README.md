# Muezzin recordings

Fasl looks for licensed recordings here, named `<voice>-<file>.mp3`:

- voices: `makkah`, `madinah`, `alafasy`, `abdulbasit`, `minshawi`, `tunisian`
- files: `adhan`, `adhan-fajr` (with "as-salatu khayrun min an-nawm"), `iqama`

Example: `alafasy-adhan-fajr.mp3`. When a file is missing, the app plays its built-in chime instead.
Recordings are not bundled: each needs a licence from its rights holder.
